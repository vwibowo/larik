Build from source

You need Go {{.Site.GoVersion}} or newer. From a checkout of the Larik repository:

{{code "bash" "go build -o larik ./cmd/larik\n./larik"}}

To run it from anywhere, put the binary on your PATH:

{{code "bash" "install -m 755 larik ~/.local/bin/larik"}}

First run

Start larik in a project directory. With nothing configured, a setup wizard finds a running Ollama or LM Studio server and any API keys in your environment, tests the connection, lists the provider's models and saves your choice. Run /connect any time to add another provider.

If you already have a key exported, Larik uses it right away:

Environment variableDefault model
ANTHROPIC_API_KEYanthropic/claude-opus-5
OPENAI_API_KEYopenai/gpt-5.5
GEMINI_API_KEYgemini/gemini-3.8-flash

No key? Use a local model through Ollama or LM Studio, or /connect codex to sign in with a ChatGPT plan.

Optional extras

  • Linux sandbox: install bubblewrap (bwrap) so shell commands run confined. macOS uses the built-in Seatbelt.
  • Windows shell: install Bash (for example, Git Bash) for the bash tool. Windows has no built-in Larik sandbox, so shell commands ask for approval.
  • Local models: Ollama or LM Studio. The wizard can download a recommended Ollama model for you.
  • Language servers such as gopls or typescript-language-server, for diagnostics after every edit.
