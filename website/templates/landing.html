12 capabilities

01

Subagents in git worktrees

Parallel subagents with fresh contexts, each on its own branch for the main agent to review and merge.

 02

Branch, rewind, undo

/fork a conversation, /rewind to before any prompt, /undo the last turn's file changes.

 03

MCP, with approval

stdio, HTTP or SSE servers with OAuth sign-in. Servers from shared project files wait for your approval.

 04

Tools on demand

With dozens of MCP tools connected, the model searches for the one it needs instead of carrying every definition.

 05

Language servers

Diagnostics after every edit, so the model sees the type error it just introduced.

 06

Web fetch and search

Pages as clean Markdown, with domain rules and cross-host redirects reported rather than followed.

 07

Browser control

A real headless Chrome in a terminal pane you can click and type in. Sign-ins persist.

 08

Permissions you control

Five modes on shift+tab. Allow and deny rules with globs; deny always wins.

 09

Auto mode

A model approves routine steps. Pushes, deletes, secrets and sudo still ask, with the reason.

 10

Plan, then approve

In plan mode the model reads, then puts its plan to you. Longer work runs from a checklist.

 11

Reviews and a GitHub Action

/review and /security-review report findings with file, line and fix.

 12

Memory

Preferences, corrections and project decisions kept as short notes and recalled in later sessions.
