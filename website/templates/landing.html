Cheap and strong model routing

Pay frontier prices only for the thinking.

An agent spends most of its tokens reading: searching files, re-reading context, making routine edits. Larik keeps your strongest model in charge of planning and review, and sends the volume work to subagents on cheap, free-tier or local models, across providers.

  • Presets in one command. /routing lists every connected model with prices and offers Balanced, Cheapest, or Local and plan first.
  • Fallbacks that don't waste a turn. A rate limit, exhausted quota or outage moves to the next model before output starts, and the failed one is left alone for a while.
  • A budget that holds. Warn at 80%, stop before the request that would cross the cap. Local and plan models count as free.
  • A leash for small models. Worktree isolation, turn caps, loop detection and a minimal prompt keep a cheap model from wrecking your checkout.
  • Measure before you trust. larik bench runs self-checking coding tasks on each candidate and reports pass/fail, cost and time.

Built in, not bolted on

Everything a serious coding agent needs.

OS sandbox, on by default

Shell commands run under Seatbelt on macOS or bubblewrap on Linux: write only to the project, no network but localhost, no way to rewrite git hooks. Sandboxed commands don't need to ask.

Subagents in git worktrees

Delegate searches and self-contained changes to parallel subagents with fresh contexts. Isolated ones work on their own branch for the main agent to review and merge. Run them in the background.

Branch, rewind, undo

Sessions are append-only transcripts. /fork a conversation, /rewind to before any prompt, /undo the last turn's file changes, and resume any of them later.

Claude Code–compatible

Your existing hooks, Agent Skills, subagent definitions, CLAUDE.md and .mcp.json work unchanged. Bring your setup; switch models.

MCP, with approval

Connect Model Context Protocol servers over stdio, HTTP or SSE. Servers from shared project files wait for your approval, pinned to a hash of their config.

Language servers

Diagnostics come back after every edit, so the model sees the type error it just introduced. An lsp tool jumps to definitions and references.

Web fetch and search

Pages come back as clean Markdown. Domain rules, blocked metadata addresses and cross-host redirects reported rather than followed. Brave, Tavily or SearXNG for search.

Permissions you control

Four modes, from plan (read-only) to yolo, cycled with shift+tab. Allow and deny rules with globs; deny always wins, in every mode.

Three front ends, one loop

Use it in the terminal, in scripts, or from your editor.

The terminal UI, headless mode and the HTTP server all read the same event stream from the same agent loop, so they behave the same way.

Terminal UI

A fast Bubble Tea interface: command palette, model picker, collapsible thinking, nested subagent activity and per-model cost.

Headless

One-shot prompts for CI and scripts, as plain text or one JSON event per line.

HTTP + SSE server

Drive sessions from an editor or web UI. Loopback only, token auth, replayable event stream.

Local-first

Runs on the model on your laptop, too.

The first-run wizard finds a running Ollama or LM Studio server and any API keys in your environment, tests the connection and can download a recommended model with a progress bar.

  • A usable context window. Larik talks to Ollama natively and asks for a 32K window instead of the 4K default, then reads back what actually loaded.
  • Honest warnings. It tells you when a request fills the window or the model can't call tools.
  • Your ChatGPT plan. /connect codex signs in with the same OAuth flow as the Codex CLI, with its own credentials file.

Designed around the loop

Small choices that keep it fast and cheap.

Cache-stable prompts

The system prompt and tool set stay fixed within a context and the transcript is append-only, so every request after the first reads from the provider's prompt cache.

Reasoning kept per model

Switch from Claude to GPT to a local model mid-session. Each block remembers which model produced it, and each model gets its own thinking replayed.

Clean compaction

When context fills, the history is replaced with one summary that names the transcript file, so the model can grep the details it left out.

One static binary

No Node or Python runtime. Build it with go build, copy it anywhere, start it in milliseconds.
